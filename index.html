ภาพรวม

ธรรมะโฆษก (Thamma Kosit) ออกแบบด้วยแนวคิด local-first แอปไม่มีระบบ login ไม่ต้องสมัครสมาชิก และไม่เก็บข้อมูลส่วนบุคคลของคุณบน server ของเรา เจตนาของแอปคือส่งต่อธรรมะโดยไม่แสวงหาผลประโยชน์ใด ๆ

ข้อมูลที่เก็บในเครื่องของคุณ

รายการโปรด, ความคืบหน้าการฟัง, รายการดาวน์โหลด, ตอนที่ฟังล่าสุด, สถิติการฟังส่วนตัว และตั้งค่าส่วนตัว เก็บอยู่ในเครื่องของคุณผ่าน local storage ของแอป คุณสามารถลบข้อมูลเหล่านี้ได้จากเมนูตั้งค่าของแอป หรือลบแอปออกจากเครื่อง

ข้อมูลที่ดึงจากเน็ตเวิร์ก

เมื่อเปิดแอป แอปจะดึงรายการตอนจาก Firebase Firestore และไฟล์เสียงจาก Cloudflare R2 การเชื่อมต่อเหล่านี้อาจมี standard HTTPS logs เช่น IP address, เวลาเชื่อมต่อ และข้อมูลทางเทคนิคของคำขอ โดยผู้ให้บริการระบบ ใช้เพื่อความปลอดภัย การป้องกันการโจมตี และการแก้ไขปัญหาทางเทคนิค

Analytics

แอปไม่ใช้ advertising identifier, tracking pixel, Firebase Analytics หรือระบบโฆษณาใด ๆ แอปมีเพียงสถิติการฟังแบบ first-party anonymous เพื่อดูตอนยอดนิยมและจำนวนผู้ฟังรวม เช่น episode id, จำนวนครั้งที่เปิดฟัง, เวลาฟังรวม, การฟังจบ, การดาวน์โหลด และ anonymous device id แบบสุ่ม ที่ไม่ผูกกับชื่อ อีเมล หรือบัญชีผู้ใช้

การแชร์ข้อมูล

เราไม่ขายข้อมูลผู้ใช้ ไม่แชร์ข้อมูลเพื่อโฆษณา และไม่ใช้ข้อมูลเพื่อติดตามคุณข้ามแอปหรือเว็บไซต์อื่น ข้อมูลทางเทคนิคอาจถูกประมวลผลโดยผู้ให้บริการ infrastructure ที่จำเป็นต่อการทำงานของแอป เช่น Firebase และ Cloudflare

เด็กและเยาวชน

แอปนี้เหมาะสำหรับทุกเพศทุกวัย ไม่มีโฆษณา ไม่มีการซื้อภายในแอป และไม่มีระบบสนทนาหรือการติดต่อระหว่างผู้ใช้

การเปลี่ยนแปลงนโยบาย

หากมีการเปลี่ยนแปลงนโยบายความเป็นส่วนตัว เราจะอัปเดตวันที่ด้านบนของหน้านี้ คุณสามารถกลับมาอ่านนโยบายฉบับล่าสุดได้จาก URL นี้
